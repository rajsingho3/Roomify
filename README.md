# Roomify

A real-time WebSocket-based chat app built with React + TypeScript. Users can create or join private chat rooms using room codes.

Demo: https://roomify-zeta.vercel.app

## Tech
- Frontend: React + TypeScript
- Backend: Node + WebSocket 
- Deployment: Vercel (frontend) / Render (Backend)

## Quick start (development)
```bash
# frontend
cd Frontend/roomify
npm install
npm run dev

# backend
cd Backend
npm install
npm run dev
